# 책 검색하기

**도서 검색**을 열고 **키워드 및 필터** 탭에서 검색해요.

## 키워드로 검색하기

1. 검색란에 단어를 입력하세요. 제목, 저자, ISBN, 출판사, 설명에서 찾아요.
2. **Enter**를 누르거나 검색 아이콘을 누르세요.
3. 검색어를 지우려면 입력란의 **x**를 누르세요.

책 한 권을 바로 찾으려면 ISBN을 입력하세요. 하이픈은 있어도 없어도 되고, 일치하는 책이 맨 앞에 나와요.

## 필터 사용하기

필터는 결과 왼쪽에 있어요. 휴대폰에서는 **필터**를 눌러 필터를 고른 뒤 **적용**을 누르세요.

- **장르**: 하나 이상 고르면 고른 장르 중 하나라도 해당하는 책이 나와요. 장르 옆 숫자는 현재 결과에 있는 책 수예요.
- **저자**: 2글자 이상 입력한 뒤 목록에서 저자를 고르세요.
- **출판 연도**: **시작**과 **끝** 연도를 입력하세요. **시작**이 **끝**보다 늦으면 오류가 표시되고 필터가 적용되지 않아요.
- **언어**와 **형식**(양장본, 문고본, 전자책, 오디오북).
- **재고 있는 책만**: 지금 살 수 없는 책을 숨겨요.
- **최소 평점**: 고른 별점 이상인 책만 보여 줘요.
- **가격**: 가격 슬라이더의 두 손잡이를 끌어서 가격 범위를 정해요.

여러 필터를 함께 쓰면 모든 조건에 맞는 책만 나와요.

## 필터 지우기

적용된 필터는 결과 위에 칩으로 표시돼요. 칩의 **x**를 누르면 그 필터만 지워지고, **모두 지우기**를 누르면 모든
필터와 키워드가 지워져요.

## 일치하는 책이 없을 때

조건에 맞는 책이 없으면 **일치하는 책이 없어요**가 표시돼요. **마지막 필터 제거**로 마지막 필터를 되돌리거나,
**도움 받기**로 도움말 도우미에게 검색 요령을 물어보세요.
