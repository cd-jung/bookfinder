# 도움말 도우미

도움말 도우미는 BookFinder 사용법을 알려 줘요. 이 사용자 가이드만 바탕으로 답하고, 특정 책에 관한 질문(검색을
이용하세요)이나 일반적인 질문에는 답하지 않아요.

## 질문하기

1. 오른쪽 아래의 **도움말**을 누르세요.
2. 질문을 입력하고 **Enter**를 누르거나 추천 질문 중 하나를 누르세요. 줄을 바꾸려면 **Shift+Enter**를 누르세요.
3. 짧은 답변을 읽고, 아래 링크를 누르면 사용자 가이드의 해당 섹션 전체가 열려요.

질문은 1000자까지 쓸 수 있고, 한도에 가까워지면 글자 수가 표시돼요. 이어서 질문하면 도우미가 바로 앞의 질문을
함께 고려해요. 도우미는 고른 표시 언어로 답해요.

답을 찾는 동안 **생성 중지**를 누르면 취소할 수 있어요.

## 답을 찾지 못할 때

사용자 가이드에 없는 내용이면 도우미는 추측하지 않고 "사용자 가이드에서 찾지 못했어요"라고 답해요. 다른 말로
물어보거나 사용자 가이드 메뉴를 살펴보세요.

## 답변 복사와 평가

복사 버튼을 누르면 답변이 복사돼요. 엄지 위 또는 아래 버튼으로 답변이 도움이 됐는지 알려 주세요. 엄지 아래를
누르면 의견을 적고 **보내기**를 누를 수 있어요.

## 대화 유지

패널을 닫았다가 다시 열어도, 같은 탭에서 페이지를 새로 고쳐도 대화가 남아 있어요. **새 대화**를 누르고
**지우기**로 확인하면 처음부터 다시 시작해요.

## 문제가 생겼을 때

도우미를 쓸 수 없거나 30초 넘게 걸리면 오류 메시지와 **다시 시도** 버튼이 표시돼요. 1분에 질문을 너무 많이 하면
몇 초 기다려 달라는 안내가 나와요.
