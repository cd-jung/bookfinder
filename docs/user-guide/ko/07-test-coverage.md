# 테스트 커버리지

**커버리지** 페이지는 BookFinder가 자동 테스트로 얼마나 확인되는지 보여 줘요. 다른 메뉴처럼 BookFinder 안에서
열리고, 배포할 때마다 새로 만들어져요. **새 탭에서 열기**를 누르면 리포트만 따로 볼 수 있어요. 리포트는 개발자용
도구라서 영어로 표시돼요.

## 페이지에 나오는 것

- **유닛 테스트**: 백엔드와 프론트엔드 코드의 파일별 라인 커버리지.
- **E2E 시나리오**: 사용자 시나리오마다 E2E 테스트가 있는지, 여정별로 묶어서 보여 줘요.
- **시나리오 그래프**: UX flow 다이어그램에서 각 단계가 테스트로 얼마나 덮였는지 테두리로 보여 줘요.

핵심 시나리오에는 별표가 붙어요. 초록색은 테스트가 있다는 뜻이고, 회색은 아직 없다는 뜻이에요.
