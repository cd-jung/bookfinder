# 로그 및 모니터링

**로그 및 모니터링** 페이지는 서비스 상태를 보여 주고 요청 로그를 검색할 수 있게 해 줘요.

## 대시보드

위쪽 카드는 최근 24시간을 보여 줘요.

- **요청 수**: API 요청 수예요.
- **오류율**: 서버 오류(5xx)로 실패한 요청의 비율이에요.
- **p95 지연 시간**: 요청의 95%가 이 시간보다 빨랐어요.
- **클라이언트 오류**: 잘못된 요청으로 거절된 수(4xx)예요.

차트는 시간별 요청 수와 서버 오류 수를 보여 줘요. **기간**에서 범위를 바꿀 수 있어요.

## 자연어로 로그 검색하기

1. `최근 1시간 동안의 오류`나 `500ms보다 느린 요청` 같은 질문을 입력하세요.
2. **Enter**를 누르세요. **해석 결과**에 질문을 어떻게 이해했는지 나와요.
3. 표에 일치하는 요청이 최신순으로 나와요.

로그 필드만 검색할 수 있어요: 시간, 메서드, 경로, 상태, 소요 시간, 수준, 메시지, 국가.
로그 검색으로 바꿀 수 없는 질문이면 다르게 질문해 달라는 안내가 나와요.

## 키워드 검색

**키워드** 탭으로 바꾸면 경로와 메시지 텍스트를 검색할 수 있고, 수준 하나로 좁힐 수도 있어요.
