# Test Coverage

The **Coverage** page shows how much of BookFinder is checked by automated tests. It opens inside BookFinder like the other menu pages
and is rebuilt on every deployment. Use **Open in a new tab** to see the report on its own.

## What the page shows

- **Unit tests**: line coverage of the backend and frontend code, per file.
- **E2E scenarios**: every user scenario, whether an end-to-end test exists for it, grouped by journey.
- **Scenario graph**: the UX flow diagrams, with each step outlined by its test coverage.

Core scenarios are marked with a star. Green means a test exists; grey means not yet.
