# Help Assistant

The Help assistant answers questions about how to use the app, using only this User Guide.

## Asking a question

1. Click **Help** in the bottom-right corner.
2. Type your question and press **Enter**. Press **Shift+Enter** for a new line.
3. Read the short answer, then click a source link to open the full guide section.

Questions can be up to 1000 characters long.

## When the assistant cannot answer

If the User Guide does not cover your question, the assistant says it could not find the answer
instead of guessing. Try other words, or browse the User Guide menu.

The assistant only explains how to use this app. It does not answer general questions.

## When something goes wrong

If the assistant is unavailable, an error message is shown with a **Retry** button.
Your question stays in the conversation, so you can retry it.
