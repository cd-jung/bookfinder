# Couverture des tests

La page **Couverture** montre la part de BookFinder vérifiée par des tests automatiques. Elle s'ouvre dans BookFinder
comme les autres pages du menu et est régénérée à chaque déploiement. Utilisez **Ouvrir dans un nouvel onglet** pour
voir le rapport seul. Le rapport est un outil pour les développeurs et il est affiché en anglais.

## Ce que montre la page

- **Tests unitaires** : couverture des lignes du code backend et frontend, par fichier.
- **Scénarios E2E** : chaque scénario utilisateur et l'existence d'un test de bout en bout, regroupés par parcours.
- **Graphe des scénarios** : les diagrammes de parcours UX, chaque étape étant encadrée selon sa couverture de tests.

Les scénarios principaux portent une étoile. Vert signifie qu'un test existe ; gris, pas encore.
