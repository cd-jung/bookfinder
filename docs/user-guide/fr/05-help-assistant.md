# Assistant d'Aide

L'assistant d'Aide explique comment utiliser BookFinder. Il répond uniquement à partir de ce Guide de l'utilisateur ; il
ne répond pas aux questions sur des livres précis (utilisez la recherche) ni aux questions générales.

## Poser une question

1. Cliquez sur **Aide**, en bas à droite.
2. Saisissez votre question et appuyez sur **Entrée**, ou cliquez sur l'une des questions suggérées. Appuyez sur **Shift+Entrée** pour aller à la ligne.
3. Lisez la réponse courte, puis cliquez sur un lien en dessous pour ouvrir la section complète du Guide de l'utilisateur.

Les questions peuvent compter jusqu'à 1000 caractères ; un compteur apparaît près de la limite. Vous pouvez poser une
question de suivi : l'assistant tient compte de votre question précédente. L'assistant répond dans votre langue d'affichage.

Pendant que l'assistant cherche la réponse, vous pouvez cliquer sur **Arrêter** pour annuler.

## Quand l'assistant ne peut pas répondre

Si le Guide de l'utilisateur ne couvre pas votre question, l'assistant répond "Je n'ai pas trouvé cela dans le Guide de
l'utilisateur" au lieu de deviner. Essayez d'autres mots ou parcourez le menu Guide de l'utilisateur.

## Copier et évaluer les réponses

Cliquez sur le bouton de copie pour copier une réponse. Utilisez les pouces vers le haut ou vers le bas pour indiquer si
une réponse vous a aidé ; après un pouce vers le bas, vous pouvez ajouter un commentaire et cliquer sur **Envoyer**.

## Votre conversation

La conversation est conservée quand vous fermez puis rouvrez le panneau, et quand vous rechargez la page dans le même
onglet. Cliquez sur **Nouvelle conversation** et confirmez avec **Effacer** pour recommencer.

## En cas de problème

Si l'assistant est indisponible ou met plus de 30 secondes à répondre, un message d'erreur s'affiche avec un bouton
**Réessayer**. Si vous posez trop de questions en une minute, il vous est demandé de patienter quelques secondes.
